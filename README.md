# Шаблоны классов

## Задание

Дано описание класса Stack, который реализует на основе односвязного списка динамическую структуру данных типа стек.

1. Разработайте реализацию класса Stack.
2. Разработайте функцию (глобальную), которая выполняет разложение на простые множители целого числа N. Для хранения множителей функция должна использовать класс Stack. Прототип функции: void Multipliers(int value, MyStack<typeName>& stack).
3. В функции main() распечатайте множители, которые функция Multipliers() записывает в стек, сначала по убыванию, а потом по возрастанию.
4. Классы ListNode и Stack необходимо упаковать в самостоятельную статическую библиотеку.
